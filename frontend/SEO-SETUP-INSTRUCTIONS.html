SEO Setup Instructions for MJ Fabrication

1. Google Analytics Setup

Add this Google Analytics code to your index.html head section:

<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=YOUR_GA_MEASUREMENT_ID"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'YOUR_GA_MEASUREMENT_ID');
</script>

2. Google Search Console Verification

Add one of these meta tags to verify your site:

<meta name="google-site-verification" content="YOUR_VERIFICATION_CODE" />

3. Submit Sitemap to Google

  1. Go to Google Search Console
  2. Select your property (mjfabrication.in)
  3. Go to Sitemaps in the left menu
  4. Submit: https://mjfabrication.in/sitemap.xml
